# Single-app workflow

Select the one app that owns the requested semantics. Establish the actual native
connection and read its app card. Discover tool schemas, inspect the input and
record important dimensions, counts, units, timing, fonts/formulas/media and
warnings before editing. Stage a copy or create a new native document.

Make bounded native calls, requesting approval when the operation warrants it.
Keep dependent calls in the same process/session. Inspect the result after
important mutations. Save the editable native document when required, and export
a separate requested delivery format to a new name under outputs/.

Check both artifacts separately. Reopen the exported result; compare the expected
structure and domain facts, and visually inspect visual formats. Check originals
and staged copies against their receipts. State exactly which checks were run.
A signature or ZIP/XML structure check is not a native round trip.

Stop on error, lock, missing dependency, unsupported format or ambiguous mutating
outcome. Keep the verified intermediate; do not silently change app, backend,
format, permissions or input. Do not install/update binaries during a session.
